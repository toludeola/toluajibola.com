# toluajibola.com

The personal site of Tolu Ajibola, Revenue Operations and GTM Systems.

**Live:** [toluajibola.com](https://toluajibola.com)

![Preview of toluajibola.com](preview.png)

## What it is

A hand-built portfolio that replaced a Framer template. It presents the revenue systems I have designed and run in production as short case studies, alongside measured outcomes, the principles I build by, and my experience.

## Built with

Astro · TypeScript · GSAP · Lenis · Netlify

## Highlights

- Light and dark themes, with a circular reveal when you switch
- Scroll-driven card decks and stats that count up each time they come into view
- Animated artwork for every system, generated from code
- Layouts that respond to the space they actually have, so a browser sidebar never squeezes them
- Respects reduced-motion settings
